---
title: REST API
description: HTTP endpoints for entries, search, KV stores, attachments, and bundles.
---

All endpoints are under `/api`. Authenticate with `Authorization: Bearer <key>` or a session cookie. Where relevant, requests accept `workspace` and `project` to scope. Interactive docs are served at `/docs` on a running server.

Multi-org users select their **active org** with the `X-Organization-ID` header — validated against membership, so naming an org you don't belong to returns `403`. See [Authentication & multi-tenancy](/reference/auth).

## Entries

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/entries` | Create an entry |
| `GET` | `/api/entries` | List / filter (category, tags, workspace, project) |
| `GET` | `/api/entries/{id}` | Get one |
| `PUT` | `/api/entries/{id}` | Update |
| `DELETE` | `/api/entries/{id}` | Delete |
| `POST` | `/api/entries/{id}/archive` | Archive |
| `GET` | `/api/entries/{id}/links` | Outgoing links + backlinks |
| `POST` | `/api/entries/{id}/resolve` | Resolve `{{references}}` and `[[wikilinks]]` |
| `POST` | `/api/search` | Dual semantic + keyword search |

## KV stores

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/kv` | List KV stores (each exposes `key_count`) |
| `POST` | `/api/kv` | Create a KV store |
| `DELETE` | `/api/kv/{store_id}` | Delete a KV store |
| `GET` | `/api/kv/{slug}/keys` | List keys (`{ store, pairs }`) |
| `GET` | `/api/kv/{slug}/keys/{key}` | Get a key |
| `PUT` | `/api/kv/{slug}/keys/{key}` | Set a key |
| `DELETE` | `/api/kv/{slug}/keys/{key}` | Delete a key |

Writes to a `repo`-canonical KV store are rejected (the bundle is the source of truth).

## Attachments

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/entries/{id}/attachments` | Upload (multipart) |
| `GET` | `/api/entries/{id}/attachments` | List for an entry |
| `GET` | `/api/attachments/{id}` | Metadata / download |
| `DELETE` | `/api/attachments/{id}` | Delete |
| `GET` | `/public/assets/{id}` | Public image serving (opt-in) |

## Bundles (repo sync)

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/bundle/push` | Validate and apply a bundle. Aborts (422) on off-spec files or drift |
| `GET` | `/api/bundle/export` | Return a rendered bundle as `{ files: [{ path, content }] }` |

## Account

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/keys` | Create an API key |
| `GET` | `/api/keys` | List keys |
| `DELETE` | `/api/keys/{id}` | Revoke a key |
| `POST` | `/api/orgs` | Create an org |
| `GET` | `/api/orgs` | List your orgs |
| `POST` | `/api/orgs/{id}/select` | Set this org as your default active org |
| `GET` | `/api/orgs/{id}/members` | List members (viewer+) |
| `POST` | `/api/orgs/{id}/members` | Invite a member (admin+) |
| `DELETE` | `/api/orgs/{id}/members/{user_id}` | Remove a member (admin+) |
| `GET` | `/api/orgs/{id}/workspaces` | List workspaces |
| `POST` | `/api/orgs/{id}/workspaces` | Create a workspace (editor+) |
| `DELETE` | `/api/workspaces/{id}` | Delete a workspace (admin+) |
| `GET` | `/api/workspaces/{id}/projects` | List projects in a workspace |
| `POST` | `/api/workspaces/{id}/projects` | Create a project (editor+) |
| `DELETE` | `/api/projects/{id}` | Delete a project (admin+) |
